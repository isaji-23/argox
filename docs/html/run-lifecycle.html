Ciclo de vida del run

Qué hace ArgoxManager.run() de principio a fin: siete fases dentro de un único span argox.agent.run, con políticas y processors intercalados.

01Las siete fases

Todo el ciclo va envuelto en el span argox.agent.run (el carril azul). Cuando enable_phase_timings=True, cada fase se cronometra en metrics.phase_timings.

02Qué graba cada fase

FaseAcciónEn caso de bloqueo

03Dos detalles de robustez

Copia del agente por run (#153). El manager instrumenta una copia shallow del agente, no la instancia compartida, porque el mismo objeto Agent suele ser conducido por run() concurrentes. Así el filtrado de tools y el wrapping nunca contaminan a un run hermano.
Export que nunca rompe el run. En el finally, cada exporter.export(metrics) va en try/except; los errores se acumulan en metrics.exporter_errors y jamás abortan la ejecución del agente.
